# Icon attribution

Every PNG in this folder was rendered from an SVG in
https://github.com/game-icons/icons (the source repository behind
https://game-icons.net). The SVGs were recoloured to the interface parchment
(`#f3e9d2`, gold `#f2b33d` for the filled star) and rasterised to 96x96 with a
transparent background. No shapes were altered.

`sources.json` in this folder maps every icon file to the exact SVG it came
from, in `author/icon-name` form, so the whole set can be regenerated.
